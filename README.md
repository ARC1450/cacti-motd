Simple MOTD/login banner plugin for Cacti. 

To install, copy to your cacti/plugins directory and unzip, changing the directory to "motd". Install from the web application, then activate.

You can create your MOTD/login banners under the "Management" nav button. 

The "login.css" files in the "themes" directories overwrite the default "loginCenter" and a few other CSS elements so that larger MOTD (like for government users) look decent.

To replace the login icon (by default, a cactus), you'll want to replace the "images/cacti_logo.svg" with your own SVG image.
